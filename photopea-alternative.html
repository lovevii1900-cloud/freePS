When to pick Photopea

  • You are doing real production editing: retouching, compositing, complex selections and layer styles.
  • The file uses smart objects, PSB format or other advanced Photoshop features.
  • You already know Photoshop's interface and want that exact workflow in a browser.

When to pick freePS

  • You just need to open and inspect a PSD — check layers, hide the background, export an asset.
  • The file is client work, an unreleased design or anything under NDA: nothing ever leaves your device.
  • You want the fastest path from "double-click PSD" to "exported PNG" with no setup and no ads in the way.
  • You are on a device where you would rather not load a full professional editor for a 2-minute job.

How the local-first workflow works

  1. Open the editor — the button above, no install or sign-up.
  2. Drop in your PSD — or use File → Open, or paste with Ctrl+V. The file is parsed in your browser memory.
  3. Work the layers — inspect, reorder, duplicate, adjust opacity; edit with brushes, clone stamp, text and filters.
  4. Export — File → Save as PNG (with transparency), JPG, WEBP, or a JSON project file for later.

No queue, no upload wait, no third party ever seeing the file. The honest trade-off: freePS deliberately does not cover the deepest professional features — very complex smart objects, unusual blend modes or missing fonts can render differently than in Photoshop, so compare carefully for final production work.
